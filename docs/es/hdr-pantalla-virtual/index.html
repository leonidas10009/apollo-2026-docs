HDR y pantalla virtual en Apollo 2026

Apollo 2026 puede crear un monitor virtual bajo demanda con la resolución, la frecuencia y el estado HDR que pide el cliente. Esta guía cubre la configuración en Windows, qué revisar cuando el HDR se ve mal y los límites de la implementación actual.

Cómo funciona la pantalla virtual

Apollo usa SudoVDA, un adaptador de pantalla virtual incluido en el instalador de Windows. Al iniciar una sesión, Apollo crea una pantalla que coincide con la configuración del cliente. Al terminarla, la elimina.

Cada cliente emparejado recibe una identidad de pantalla fija. Windows recuerda la resolución, la posición y los ajustes HDR de esa identidad, así que la misma tablet o TV conserva su configuración entre sesiones sin scripts ni cambios manuales.

Elimina primero otras soluciones de pantalla virtual. Los dummy plugs, los drivers IDD de fabricante y los monitores virtuales antiguos pueden entrar en conflicto con SudoVDA y provocar pantallas negras o displays duplicados. Desactívalos en el Administrador de dispositivos y en la configuración de Apollo antes de investigar cualquier otra cosa.

Configuración

  1. Activa HDR en el host

    Abre Configuración → Sistema → Pantalla → HDR y actívalo. El HDR requiere Windows 11 23H2 o superior (se recomienda 24H2). Si el PC no tiene un monitor HDR conectado, Windows puede ocultar la opción; un emulador EDID o la propia pantalla virtual pueden proporcionar un destino compatible con HDR.

  2. Confirma que SudoVDA está instalado

    En el Administrador de dispositivos, busca SudoMaker Virtual Display Adapter en Adaptadores de pantalla. Si no aparece, vuelve a ejecutar el instalador de Apollo y mantén seleccionado el componente de pantalla virtual.

  3. Configura la pantalla virtual en Apollo

    En la Web UI, abre Configuration → Audio/Video y revisa las opciones de pantalla virtual. Las importantes son:

    • Virtual display: crea la pantalla al iniciar la sesión.
    • Opción HDR: en auto sigue la petición del cliente cuando la pantalla lo soporta.
    • Modo de reserva: resolución cuando el cliente no pide una, en formato AnchoxAltoxFPS.
    • Pantalla virtual aislada: mueve la pantalla virtual para que no se superponga a un monitor físico.

  4. Activa HDR en el cliente

    En Moonlight o Artemis 2026, abre los ajustes de la sesión y activa HDR. Si la opción del cliente está desactivada, el host envía SDR y un escritorio HDR puede verse sobreexpuesto.

  5. Calibra

    Emite la app Windows HDR Calibration al cliente y guarda un perfil para streaming. Puede que aún tengas que ajustar el brillo y la calibración HDR del juego, porque el panel del cliente suele ser menos brillante que un monitor de escritorio.

Cuando el HDR se ve mal

Imagen lavada o gris

Probablemente el stream es SDR mientras el escritorio del host está en HDR. Revisa primero el interruptor HDR del cliente y después la opción HDR de Apollo.

Colores incorrectos solo en la pantalla virtual

Algunas configuraciones de pantalla virtual informan mal del estado HDR. Apollo incluye un workaround opcional que apaga y vuelve a encender HDR al iniciar la sesión. Configura dd_wa_hdr_toggle_delay = 500 y prueba. Déjalo en 0 salvo que tengas el problema: añade retardo a cada inicio de stream.

No aparece la opción HDR

Puede que el codificador de la GPU no soporte HEVC Main 10 o AV1 10 bits. Revisa la lista de codificadores en la Web UI, actualiza el driver de la GPU y prueba HEVC en lugar de AV1 (o al contrario).

La sesión empieza en el monitor equivocado

Activa Pantalla virtual aislada o fija la posición explícitamente. Windows también puede recordar una distribución de una identidad de cliente anterior; elimina el cliente emparejado y vuelve a emparejarlo para reiniciar la configuración.

Linux y macOS

La pantalla virtual SudoVDA es exclusiva de Windows. El HDR está soportado oficialmente en hosts Windows y es experimental en Linux, donde requiere el backend de captura KMS y un compositor con soporte HDR, como Gamescope o KDE Plasma 6. La captura X11 y NvFBC no soportan HDR.

En Linux, las salidas virtuales las proporciona el compositor (por ejemplo una salida wlroots en Hyprland), no Apollo.

Portátiles con doble GPU: si la pantalla virtual se crea en la GPU integrada, la captura puede hacerse desde el adaptador equivocado. El README del proyecto documenta la configuración recomendada para gráficos híbridos.
