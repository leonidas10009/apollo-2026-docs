Preguntas frecuentes y solución de problemas

Respuestas cortas a lo que más se pregunta: avisos al instalar, problemas con la pantalla virtual, HDR, emparejamiento, mandos y Android TV. Cada respuesta enlaza a la guía con el procedimiento completo.

¿Apollo 2026 es gratis?

Sí. Apollo 2026 es gratis y de código abierto bajo GPL-3.0. Los binarios están en GitHub Releases y el código completo en el repositorio. No requiere cuenta, suscripción ni telemetría.

¿Es el Apollo o el Sunshine oficial?

No. Apollo 2026 es un fork independiente y no oficial del ecosistema Apollo / Sunshine / Moonlight. Está basado en el código de Sunshine 2026 y continúa el trabajo del Apollo original, pero no está afiliado a ClassicOldSong, LizardByte ni Moonlight Stream. Todo el crédito de los proyectos originales es de sus autores.

¿Funciona con Moonlight?

Sí. Apollo 2026 es compatible con los clientes Moonlight en Windows, macOS, Linux, iOS, Android y Android TV. Artemis 2026 añade funciones específicas de Apollo, como control de pantalla virtual, portapapeles y energía remota.

Windows dice «Editor desconocido». ¿La descarga es segura?

El ejecutable y el instalador actuales no están firmados, así que SmartScreen muestra el aviso genérico. Verifica el SHA-256 publicado en la página de release o compila desde el código fuente. El hash esperado de Apollo-1.0.2-win64-setup.exe es 8b2e9d49ebee2418e0d02e5adcbd93a268d274349387e5ee45c7d9b881e7338f.

La pantalla virtual no aparece al iniciar una sesión

Revisa tres cosas: que SudoVDA esté instalado (el Administrador de dispositivos muestra SudoMaker Virtual Display Adapter), que la opción de pantalla virtual esté activa en la Web UI de Apollo y que no haya otro monitor virtual o dummy plug activo. Apollo recomienda eliminar otras soluciones de pantalla virtual para evitar conflictos. Consulta la guía de HDR y pantalla virtual.

El HDR se ve lavado o sobreexpuesto

Normalmente el cliente recibe SDR mientras el escritorio del host está en HDR. Activa HDR en Moonlight o Artemis y confirma que la opción HDR de Apollo está en auto. Si solo se ven mal los colores en la pantalla virtual, prueba dd_wa_hdr_toggle_delay = 500; déjalo desactivado en caso contrario porque retrasa cada inicio de sesión.

No puedo abrir la Web UI

Usa https://localhost:47990 en el host. Comprueba que el servicio de Apollo está en marcha y que existe la regla de firewall. El certificado es autofirmado, así que acepta el aviso del navegador una vez. Si cambiaste el puerto, usa el nuevo.

He olvidado el usuario o la contraseña de la Web UI

Abre una consola de administrador donde esté instalado apollo.exe y ejecuta apollo.exe --creds <nuevo-usuario> <nueva-contraseña>. Reinicia el servicio después si el cambio no se aplica al momento.

El mando funciona en Steam pero no en los juegos

Apollo necesita un backend de gamepad virtual. En Windows, el instalador incluye SudoVDA pero no ViGEmBus ni el Virtual HID Broker. Instala el backend que quieras por separado: ViGEmBus 1.22.0 es la alternativa gratuita para Xbox 360 y DualShock 4, mientras que el Virtual HID Broker es una descarga licenciada aparte con soporte para DualSense, Switch Pro y movimiento. Consulta la guía de solución de problemas upstream.

Mi cliente no encuentra el PC

Confirma que ambos dispositivos están en la misma subred, que el perfil de red de Windows es Privado y que la regla de firewall existe. Las VPN, el Wi-Fi de invitados y el aislamiento de clientes del router pueden bloquear el descubrimiento. Añadir el host por IP es la solución más rápida.

Play Protect bloquea Artemis 2026 en mi TV

El APK 1.0.3 ya no declara el servicio de accesibilidad ni los permisos sensibles que provocaban el aviso. Desinstala la versión bloqueada, reinicia la TV y vuelve a instalar el APK arm64 o universal. En Samsung, revisa Auto Blocker; en Android 16, Protección avanzada. La guía de Android TV lista el resto de alternativas.

¿Puedo emitir por internet, no solo por LAN?

Sí, pero no es la configuración por defecto ni una solución llave en mano. Necesitas una VPN o abrir el rango de puertos correctamente, una ruta estática o DNS dinámico y una contraseña fuerte en la Web UI. Una VPN como WireGuard o Tailscale es más sencilla y segura que exponer el host directamente.

¿Apollo 2026 funciona en Linux?

El código soporta Linux y la documentación upstream lo cubre, pero este fork publica actualmente solo builds para Windows x64. Los usuarios de Linux deben compilar desde el código fuente. La pantalla virtual SudoVDA es exclusiva de Windows; el HDR en Linux es experimental y requiere captura KMS y un compositor compatible con HDR.

¿Cómo actualizo?

Descarga el nuevo instalador desde la página de releases y ejecútalo sobre la instalación existente. La configuración, las apps y los emparejamientos se conservan. No mezcles instalador y formato portable en la misma instalación; desinstala el formato anterior primero.

¿Dónde reporto un fallo o pido ayuda?

Abre un issue en github.com/leonidas10009/Apollo_2026/issues con la versión de Apollo, la versión de Windows, la GPU, el cliente y una descripción de lo que probaste. Las discusiones están activas para preguntas que no sean fallos. Para Artemis 2026, usa el tracker de Artemis.

¿Sigues atascado? La documentación upstream tiene secciones detalladas de solución de problemas, configuración y ajuste de rendimiento.
