Install Apollo 2026 on Windows 11 or 10

The Windows installer is the recommended way to run the host. It sets up the service, the firewall rules and the bundled SudoVDA virtual display driver. This guide takes you from download to your first stream.

Before you start: the current release publishes Windows x64 builds only: an installer (Apollo-1.0.2-win64-setup.exe) and a portable ZIP. Linux, macOS and FreeBSD users need to build from source using the upstream documentation.

The Windows binaries are not code-signed, so SmartScreen may show “Unknown publisher”. Verify the SHA-256 below before running the file.

Step by step

  1. Download the installer

    Get Apollo-1.0.2-win64-setup.exe from the Apollo 2026 releases page.

    Optional but recommended: check the hash in PowerShell before running it.

    Get-FileHash .\Apollo-1.0.2-win64-setup.exe -Algorithm SHA256

    Expected: 8b2e9d49ebee2418e0d02e5adcbd93a268d274349387e5ee45c7d9b881e7338f

  2. Run the installer

    Choose the components you actually need. Keep the SudoVDA virtual display option enabled if you want HDR virtual displays and automatic client resolution. The installer also creates the Windows firewall rules.

    If SmartScreen appears, select More info → Run anyway after verifying the hash.

  3. Open the Web UI

    Apollo starts in the notification area. Open https://localhost:47990 and create the administrator username and password on the welcome page.

    The certificate is self-signed, so the browser will warn you once. This is expected on a local host.

  4. Pair your client

    Install Moonlight or Artemis 2026 on the device you want to play on. In the client, add the host and enter the PIN shown by the client.

    In the Apollo Web UI, open PIN, enter the code and approve the device. Artemis clients can also use OTP/QR pairing from the same page.

  5. Start a stream

    Pick Desktop or one of your apps. When the session starts, Apollo creates the virtual display, matches the client resolution and refresh rate, and removes it when the app closes.

If you use the portable ZIP, open an administrator command prompt in the extracted folder and run scripts\add-firewall-rule.bat, then scripts\install-service.bat and scripts\autostart-service.bat.

Check that it worked

  • The Apollo icon is visible in the notification area.
  • https://localhost:47990 loads and accepts your credentials.
  • Device Manager shows SudoMaker Virtual Display Adapter under Display adapters.
  • A client can see the host on the local network and pair successfully.

Installing on a laptop with two GPUs? The virtual display may be attached to the integrated GPU. See the dual-GPU section in the project README before changing encoder settings.

Common install problems

The Web UI does not load

Check that the Apollo service is running and that the firewall rule exists. If you changed the Web UI port, use the new one. A forgotten password can be reset from an administrator terminal with apollo.exe --creds <user> <password>.

No virtual display appears when streaming

Confirm that SudoVDA is installed and that no other virtual display driver (for example a dummy plug or a third-party IDD) is active. Apollo recommends removing other virtual display solutions to avoid conflicts.

The client cannot find the PC

Make sure the network profile is Private, the firewall rule is present, and both devices are on the same subnet. VPNs and client isolation on the router can block discovery.
