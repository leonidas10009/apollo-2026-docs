Stream your PC to Android TV with Artemis 2026

Artemis 2026 is the Android client built for Apollo 2026. It includes a leanback launcher for Android TV and Google TV, works with a remote or gamepad, and adds Apollo-specific controls such as virtual display switching and remote power actions.

Unofficial fork. Artemis 2026 is based on Artemis / Moonlight Noir and Moonlight. It is not affiliated with ClassicOldSong, Moonlight Stream or LizardByte. The package name is different from the official Artemis app, so both can be installed side by side without sharing pairings.

Which APK do I need?

Install on Android TV or Google TV

  1. Allow installs from unknown sources

    On the TV, open Settings → Apps → Security & restrictions → Install unknown apps and allow the app you will use to open the APK, for example Downloader or your file manager.

  2. Get the APK onto the device

    Android TV usually has no browser. The simplest options are:

    • Install Downloader from the Play Store and enter the release URL, or a short link you create yourself.
    • Copy the APK to a USB drive and open it with a file manager.
    • Use adb install Artemis-1.0.3-arm64-v8a.apk from a computer on the same network.

  3. Install and open Artemis

    The app appears in the leanback launcher. It does not require a touchscreen; the TV remote and gamepads work for navigation.

  4. Find your PC

    Both devices must be on the same network. Artemis scans for Apollo and Moonlight-compatible hosts automatically. If discovery fails, add the host by IP address.

  5. Pair

    Start pairing in Artemis, then approve the PIN in the Apollo Web UI under PIN. Artemis also supports OTP/QR pairing, which avoids typing a code with the TV remote.

Play Protect blocks the install

Android may show “App blocked to protect your device” when installing an APK from a browser, messenger or file manager. The warning comes from Play Protect, not from the APK signature. Artemis 1.0.2 removed the accessibility service that used to trigger it, and 1.0.3 no longer declares sensitive permissions.

  • Uninstall the blocked version, reboot the TV and install Artemis-1.0.3-arm64-v8a.apk or the universal APK.
  • On Samsung devices, check Auto Blocker. On Android 16, check Advanced protection.
  • As a last resort, temporarily disable Play Store → Profile → Play Protect → Scan apps with Play Protect, install, then re-enable it.
  • Installing over ADB with verifier_verify_adb_installs=0 also works; restore the setting afterwards.

Apollo-specific features

Virtual display control

Start a stream on a virtual display and switch modes from the client without touching the host.

Remote power

Shut down, restart or cancel a pending shutdown from the PC page. Requires Apollo 1.0.1 or later and the server_cmd permission for that client.

Clipboard sync

Copy text between the client and the host when the permission is granted.

App actions

Start, resume, close, hide or export an app as an .art launcher file for emulator frontends.

Best results on a TV: use a wired connection on the host, 5 GHz Wi-Fi or Ethernet on the TV, and enable HDR on both sides if the panel supports it. See HDR and virtual display.

Requirements

  • Android 8.0 or newer is a safe baseline for current Artemis builds; very old boxes may not work.
  • Apollo 2026 on the host, or a Sunshine host for the standard Moonlight features.
  • Host and client on the same local network for discovery and pairing.
