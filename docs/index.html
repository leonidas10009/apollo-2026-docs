Self-hosted game streaming · Windows & Linux

Your PC games, streamed with HDR and low latency.

Apollo 2026 is an independent, self-hosted game streaming host. It keeps the Sunshine 2026 streaming core and adds HDR virtual displays, a modern Web UI, per-client permissions and first-class support for Artemis 2026 on Android and Android TV.

What is Apollo 2026?

Apollo 2026 runs on the gaming PC. It captures the desktop or a game, encodes the video with the GPU and streams it over your local network to a Moonlight-compatible client. There is no cloud account and no subscription: the host and the client talk directly to each other.

It is a continuation of Apollo by ClassicOldSong, built on the Sunshine 2026 codebase. Apollo 2026 is an independent, unofficial fork maintained by Leonidas. It is not affiliated with the upstream projects, and all credit for the original work belongs to their authors.

New to game streaming? You need two pieces: a host on the gaming PC (Apollo 2026) and a client on the device you play on (Moonlight or Artemis 2026). Start with the Windows install guide.

What it adds to Sunshine

Display

HDR virtual display

SudoVDA creates a virtual monitor on demand, matches the client resolution and refresh rate, and keeps a fixed identity per client. No dummy plug and no manual resolution switching.

Control

Modern Web UI

Pair clients, edit apps, manage permissions and change audio/video settings from a responsive dashboard with a command palette and themes.

Security

Per-client permissions

Grant input, clipboard, app launch and server commands per device. The first paired client gets full access; later clients start restricted.

Performance

Hardware encoding

Use NVIDIA NVENC, AMD AMF, Intel Quick Sync or a software encoder. H.264, HEVC and AV1 work where the GPU and client support them.

Clients

Android and Android TV

Artemis 2026 adds Apollo-specific features: virtual display control, clipboard sync, remote power actions and a leanback launcher for TV.

Latency

Native client resolution

Stream at the client's native resolution and frame rate, with low-latency tuning inherited from the Sunshine 2026 core.

How it works

  1. Install the host

    Run the Windows installer (recommended) or use the portable package. The installer bundles the SudoVDA virtual display driver. On Linux, macOS and FreeBSD, build from source.

    Windows installation guide →

  2. Pair a client

    Open the Web UI at https://localhost:47990, then pair Moonlight, Artemis 2026 or Artemis PC with a PIN or an OTP/QR code. Grant the permissions that client needs.

    Android TV setup →

  3. Play

    Launch a game or the desktop from the client. Apollo creates the virtual display when the stream starts and removes it when the session ends.

Common questions

Is Apollo 2026 free?

Yes. Apollo 2026 is free and open source under GPL-3.0. You can download the binaries from GitHub Releases and build it from source.

Is it the official Apollo or Sunshine?

No. Apollo 2026 is an independent, unofficial fork in the Apollo / Sunshine / Moonlight ecosystem. It is not affiliated with ClassicOldSong, LizardByte or Moonlight Stream.

Does it work with Moonlight?

Yes. Apollo 2026 is compatible with Moonlight clients. Artemis 2026 adds Apollo-specific features such as virtual display control and remote power actions.
