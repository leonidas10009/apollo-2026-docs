Apollo 2026 FAQ and troubleshooting

Short answers to the questions that come up most often: install warnings, virtual display problems, HDR, pairing, controllers and Android TV. Each answer links to the guide with the full procedure.

Is Apollo 2026 free?

Yes. Apollo 2026 is free and open source under GPL-3.0. Binaries are on GitHub Releases and the full source is in the repository. There is no account, subscription or telemetry requirement.

Is this the official Apollo or Sunshine?

No. Apollo 2026 is an independent, unofficial fork in the Apollo / Sunshine / Moonlight ecosystem. It is based on the Sunshine 2026 codebase and continues the original Apollo work, but it is not affiliated with ClassicOldSong, LizardByte or Moonlight Stream. All credit for the original projects belongs to their authors.

Does it work with Moonlight?

Yes. Apollo 2026 is compatible with Moonlight clients on Windows, macOS, Linux, iOS, Android and Android TV. Artemis 2026 adds Apollo-specific features such as virtual display control, clipboard sync and remote power actions.

Windows says “Unknown publisher”. Is the download safe?

The current Windows executable and installer are not code-signed, so SmartScreen shows the generic warning. Verify the SHA-256 published on the release page, or build from source if you prefer. The expected hash for Apollo-1.0.2-win64-setup.exe is 8b2e9d49ebee2418e0d02e5adcbd93a268d274349387e5ee45c7d9b881e7338f.

The virtual display does not appear when I start a stream

Check three things: SudoVDA is installed (Device Manager shows SudoMaker Virtual Display Adapter), the virtual display option is enabled in the Apollo Web UI, and no other virtual monitor or dummy plug is active. Apollo recommends removing other virtual display solutions to avoid conflicts. See the HDR and virtual display guide.

HDR looks washed out or overexposed

Usually the client is receiving SDR while the host desktop is in HDR. Enable HDR in Moonlight or Artemis, then confirm the HDR option in Apollo is set to auto. If only the virtual display shows wrong colors, test dd_wa_hdr_toggle_delay = 500; leave it disabled otherwise because it delays every stream start.

I cannot open the Web UI

Use https://localhost:47990 on the host. Check that the Apollo service is running and that the firewall rule exists. The certificate is self-signed, so accept the browser warning once. If you changed the port, use the new one.

I forgot the Web UI username or password

Open an administrator terminal where apollo.exe is installed and run apollo.exe --creds <new-user> <new-password>. Restart the service afterwards if the change does not take effect immediately.

The controller works in Steam but not in games

Apollo needs a virtual gamepad backend. On Windows, the Windows installer bundles SudoVDA but not ViGEmBus or the Virtual HID Broker. Install the backend you want separately: ViGEmBus 1.22.0 is a free fallback for Xbox 360 and DualShock 4, while the Virtual HID Broker is a separate licensed download with DualSense, Switch Pro and motion support. See the upstream troubleshooting guide.

My client cannot find the PC

Confirm that both devices are on the same subnet, the Windows network profile is Private, and the firewall rule is present. VPNs, guest Wi-Fi and router client isolation can block discovery. Adding the host by IP address is the fastest workaround.

Play Protect blocks Artemis 2026 on my TV

The 1.0.3 APK no longer declares the accessibility service or sensitive permissions that triggered the warning. Uninstall the blocked version, reboot the TV and reinstall the arm64 or universal APK. On Samsung, check Auto Blocker; on Android 16, check Advanced protection. The Android TV guide lists the remaining workarounds.

Can I stream over the internet, not just my LAN?

Yes, but it is not the default and it is not a supported turnkey setup. You need a VPN or a correctly forwarded port range, a static route or dynamic DNS, and a strong Web UI password. A VPN such as WireGuard or Tailscale is simpler and safer than exposing the host directly.

Does Apollo 2026 run on Linux?

The codebase supports Linux and the upstream documentation covers it, but the current fork publishes Windows x64 builds only. Linux users need to build from source. The SudoVDA virtual display is Windows-only; HDR on Linux is experimental and requires KMS capture plus an HDR-capable compositor.

How do I update?

Download the new installer from the releases page and run it over the existing installation. Your configuration, apps and pairings are preserved. Do not mix installer and portable formats in the same installation; uninstall the previous format first.

Where do I report a bug or ask for help?

Open an issue at github.com/leonidas10009/Apollo_2026/issues with the Apollo version, Windows version, GPU, client and a description of what you tried. Discussions are enabled for questions that are not bugs. For Artemis 2026, use the Artemis issue tracker.

Still stuck? The upstream documentation has detailed sections on troubleshooting, configuration and performance tuning.
