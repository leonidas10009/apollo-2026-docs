Instalar Apollo 2026 en Windows 11 o 10

El instalador de Windows es la forma recomendada de ejecutar el host. Configura el servicio, las reglas de firewall y el driver de pantalla virtual SudoVDA incluido. Esta guía va desde la descarga hasta tu primera partida.

Antes de empezar: la versión actual publica solo binarios para Windows x64: un instalador (Apollo-1.0.2-win64-setup.exe) y un ZIP portable. En Linux, macOS y FreeBSD hay que compilar desde el código fuente con la documentación upstream.

Los binarios de Windows no están firmados, así que SmartScreen puede mostrar «Editor desconocido». Verifica el SHA-256 antes de ejecutar el archivo.

Paso a paso

  1. Descarga el instalador

    Obtén Apollo-1.0.2-win64-setup.exe desde la página de releases de Apollo 2026.

    Opcional pero recomendable: comprueba el hash en PowerShell antes de ejecutarlo.

    Get-FileHash .\Apollo-1.0.2-win64-setup.exe -Algorithm SHA256

    Esperado: 8b2e9d49ebee2418e0d02e5adcbd93a268d274349387e5ee45c7d9b881e7338f

  2. Ejecuta el instalador

    Elige los componentes que realmente necesitas. Mantén activada la opción pantalla virtual SudoVDA si quieres HDR y resolución automática por cliente. El instalador también crea las reglas de firewall de Windows.

    Si aparece SmartScreen, pulsa Más información → Ejecutar de todas formas después de verificar el hash.

  3. Abre la Web UI

    Apollo se inicia en el área de notificación. Abre https://localhost:47990 y crea el usuario y la contraseña de administrador en la página de bienvenida.

    El certificado es autofirmado, así que el navegador avisará una vez. Es lo esperado en un host local.

  4. Empareja el cliente

    Instala Moonlight o Artemis 2026 en el dispositivo con el que quieras jugar. En el cliente, añade el host e introduce el PIN que muestra el cliente.

    En la Web UI de Apollo, abre PIN, introduce el código y aprueba el dispositivo. Los clientes Artemis también pueden usar emparejamiento OTP/QR desde la misma página.

  5. Inicia una sesión

    Elige Escritorio o una de tus apps. Al iniciar la sesión, Apollo crea la pantalla virtual, ajusta la resolución y la frecuencia al cliente y la elimina cuando cierras la app.

Si usas el ZIP portable, abre una consola de administrador en la carpeta extraída y ejecuta scripts\add-firewall-rule.bat, después scripts\install-service.bat y scripts\autostart-service.bat.

Comprueba que funciona

  • El icono de Apollo aparece en el área de notificación.
  • https://localhost:47990 carga y acepta tus credenciales.
  • El Administrador de dispositivos muestra SudoMaker Virtual Display Adapter en Adaptadores de pantalla.
  • Un cliente ve el host en la red local y se empareja correctamente.

¿Instalas en un portátil con dos GPU? Puede que la pantalla virtual se cree en la GPU integrada. Consulta la sección de doble GPU del README del proyecto antes de cambiar el codificador.

Problemas habituales de instalación

La Web UI no carga

Comprueba que el servicio de Apollo está en marcha y que existe la regla de firewall. Si cambiaste el puerto de la Web UI, usa el nuevo. Si olvidaste la contraseña, puedes restablecerla desde una consola de administrador con apollo.exe --creds <usuario> <contraseña>.

No aparece la pantalla virtual al emitir

Confirma que SudoVDA está instalado y que no hay otro driver de pantalla virtual activo (por ejemplo un dummy plug o un IDD de terceros). Apollo recomienda eliminar otras soluciones de pantalla virtual para evitar conflictos.

El cliente no encuentra el PC

Asegúrate de que el perfil de red es Privado, la regla de firewall existe y ambos equipos están en la misma subred. Las VPN y el aislamiento de clientes del router pueden bloquear el descubrimiento.
